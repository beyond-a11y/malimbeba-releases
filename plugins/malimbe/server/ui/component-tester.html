Malimbe · Component Tester

Render your component, audit what actually appears.

Web components build their markup at runtime inside shadow DOM, so parsing source finds nothing. This renders your code in an isolated frame and walks the flattened tree — checking computed contrast, real focus indicators, rendered target size, and shadow-scoped ARIA references.
