Stories from the field

A working example of the Malimbe carousel web component. Use the previous and next buttons, or press Start to let the slides rotate. Rotation holds while you hover over the carousel and stops when keyboard focus moves into a slide control.

Reference component, not release-gated. This example is for developers. It has not passed the enterprise release gate, and its manual accessibility reviews are not complete.
