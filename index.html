What it does

Three jobs, one tool.

Malimbe is an MCP server plus encoded expertise. It rides inside the coding agent you already use, so accessibility happens where the code is written — not in a scan after the fact.

Build

Describe a component in plain words. Malimbe maps it to the correct ARIA pattern and writes a prompt carrying the full keyboard and focus contract — the parts agents usually get wrong.

Review

Audit a live site, an internal URL, a repo, or code that isn't hosted yet — served locally and scanned for real. Findings ranked by how badly they block a user, not raw counts.

Govern

A release gate with enforced provenance, a component manifest that remembers verdicts and expires exceptions, and consistency checks across a whole design system.

How it fits

One line in your editor config.

Malimbe is model- and platform-agnostic. The same package serves every agentic surface through the standard MCP protocol — no lock-in to one assistant.

  • Ships pre-built — install the package, no compiling on your end
  • Finds your installed Chrome or Edge automatically; no forced downloads, no mysterious hangs
  • malimbeba doctor hands you your exact, ready-to-paste editor config — no path-guessing
  • Static checks always work, even with no browser present

Install, then let doctor configure your editor

Download malimbeba-0.4.3.tgz from the 0.4.3 beta release, then run:

npm install -g ./malimbeba-0.4.3.tgz
malimbeba doctor

Prints your MCP config with the correct path already filled in for your install — copy it as-is into your editor.

Why Malimbe

Honest about what a machine can and can't verify.

Most accessibility tooling either flags defects after the fact or overpromises "one-click compliance." Malimbe does neither. It works where code is generated, enforces evidence, and is candid about its limits.

Automated checks are necessary, not sufficient. Malimbe tells you what it verified, what it couldn't, and what still needs a human.

The provenance gate

Every release verdict is tied to a named, auditable artifact — a deployed URL, a package version, a build SHA. Pasted or unverifiable code can't pass the automated gate. It's a direct, enforced answer to the fair question "can I trust an AI to judge accessibility?"
